The Problem

NISRA provides recreation programs for individuals with disabilities, but their website failed basic accessibility standards. Small text, poor contrast, and unclear forms prevented visually impaired users from signing up independently.

"How might we improve website accessibility so users with visual impairments can read content, navigate pages, and complete tasks without frustration or assistance?"

Three Critical Accessibility Barriers

1
Small Text Size

Users with low vision couldn't read program details or form fields, requiring assistance to navigate basic tasks.

2
Poor Color Contrast

Text blended into backgrounds, failing WCAG standards (below 4.5:1 ratio). Users described it as "straining to read."

3
Unclear Form Labels

Sign-up fields lacked descriptive labels, causing confusion and screen reader incompatibility. Users called it "a guessing game."

1. Competitive Analysis

Tools Used: WebAIM tools, comparison matrices, accessibility checkers
Methods Applied: Benchmarking accessibility features against NWSRA and FVSRA

What I Did: Analyzed NISRA against two similar organizations (Northwest Special Recreation Association and Fox Valley Special Recreation Association) to benchmark accessibility features.

Key Finding: Competitors had better accessibility features across the board - text resize options, WCAG compliant contrast, clear form labels, screen reader compatibility, and consistent alt text. NISRA's poor contrast, small text, and unclear forms made it significantly harder to use.

2. Contextual Inquiries

Tools Used: Zoom for remote observation, screen recording, task observation protocols
Methods Applied: Direct observation of 10 participants with visual impairments interacting with NISRA's website

Tasks Observed: Navigate to programs page, read program descriptions, locate and complete sign-up form, use assistive technologies (screen readers when applicable)

Key Findings: Users couldn't easily read program info due to small font size. Low contrast made reading difficult for users with low vision. Users found it difficult to complete the sign-up form because the labels were unclear.

3. Semi-Structured Interviews

Tools Used: Zoom, interview guides, Miro for affinity mapping
Methods Applied: 10 user interviews via Zoom with both registered and non-registered NISRA users

Key Questions: What's the hardest part about using the NISRA website? Have you tried signing up for a program? Do you use screen readers or other assistive tools? What would make it easier to find and sign up for programs?

Key Themes: Text unreadable (size and contrast made content inaccessible), forms confusing (missing labels caused errors), lack of confidence (users required assistance), screen reader issues (poor semantic HTML broke assistive tech)

10 participants via Zoom

4. Accessibility Audit (WCAG 2.0 AA)

Tools Used: WebAIM's Contrast Checker, WAVE accessibility tool
Methods Applied: WCAG 2.0 AA compliance audit, contrast ratio testing

What I Did: Audited key pages and documented specific failures. Required contrast: 4.5:1 for normal text, 3:1 for large text.

Audit Results: Body text 3.2:1 (Failed), Form labels 2.8:1 (Failed), Program titles 2.5:1 (Failed), Button text 3.9:1 (Failed). The audit confirmed what users told us - the site objectively failed accessibility standards in areas critical for sign-ups.

Project Summary

Through systematic UX research and accessibility audits, I identified critical barriers preventing visually impaired users from accessing NISRA's website independently.

By implementing text resize controls, WCAG-compliant color contrast, and clear form labels, the redesign achieved a 20% increase in program sign-ups, with 85% of users reporting the site was easier to use.

Key to success: User-centered research with visually impaired participants revealed specific pain points that informed targeted, measurable accessibility improvements.
